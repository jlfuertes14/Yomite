# Yomite v1.3.2

This release focuses on diagnosing and stabilizing Android release push subscriptions. It adds an in-app diagnostics panel so device registration can be verified without Android Studio, improves standalone Expo notification detection, and adds detailed server-side logs for release subscriptions and Anime News requests.

## Release Notification Diagnostics

- Added a Release Notification Diagnostics panel to Settings.
- Displays Android notification permission status.
- Displays the Expo execution environment.
- Displays whether the EAS project ID is configured.
- Displays Expo Notifications module availability.
- Displays whether a push token is stored locally.
- Displays the last registration result, HTTP status, and sanitized error message.
- Added a Retry Registration action for testing device subscription registration.

## Android Push Subscription Fixes

- Updated standalone APK detection to use Expo SDK 57's execution environment.
- Prevents standalone Android builds from being incorrectly treated as Expo Go.
- Added clearer diagnostics for missing permissions, missing project IDs, unavailable notification modules, and failed Expo token generation.
- Added parser response diagnostics for failed subscription requests.

## Release Service Improvements

- Fixed Supabase requests using `return=minimal` and returning an empty response body.
- Added safe handling for successful empty Supabase responses.
- Added clear errors when Supabase service configuration is missing.
- Added Render logs for release subscription requests and Supabase responses.

## Anime News Service Diagnostics

- Added logs for Anime News Network feed attempts and failures.
- Added logs for Anime Corner feed attempts and failures.
- Added feed cache, article enrichment, and API request logs.
- Added sanitized error information for failed news requests.
