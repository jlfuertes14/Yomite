# Yomite v1.3.1

This release improves Yomite's Android update delivery, notification reliability, and release experience. Updates are now prepared from a detailed release document and delivered through the Yomite release service instead of making the app query GitHub directly.

## App Updates

- Moved Android release detection from the mobile app to the `yomite-parser` release service.
- Added a release manifest endpoint for the current stable Android release.
- Added server-side release synchronization after a GitHub release is published.
- Added Supabase-backed release records and device push subscriptions.
- Added Expo push notifications for subscribed Android devices, including notifications when Yomite is closed.
- Added notification tap handling that opens the in-app update modal.
- Kept launch and resume checks as a fallback when a push notification is delayed or unavailable.
- Added support for temporary update snoozing with the Later action.
- Closing the update modal with X no longer permanently hides that release.

## Release Notes and APK Delivery

- Release publishing now requires `release-notes/v{version}.md`.
- GitHub Releases use the checked-in detailed release notes instead of a raw commit-title fallback.
- Existing draft releases are updated with the latest detailed release notes before publication.
- The universal APK is preferred for in-app installation, with an ABI-specific fallback for older releases.
- Added APK download progress inside the Install Update button.
- Removed the duplicate progress line below the changelog.
- Added an Expo development preview that simulates download progress without installing an APK.

## Notifications

- Added notification permission setup during native app startup.
- Android notification channels are created before requesting permission on Android 13 and newer.
- Granted notification permission automatically registers the device for Yomite release alerts.
- Disabling notifications unregisters the device from release subscriptions.
- Release notifications continue using the Yomite monochrome Android notification icon.

## Navigation and Reader Experience

- Restored the Discover floating navigation bar whenever the Discover screen regains focus.
- Removed the reader's full-screen spinner and text while automatic manga/manhwa reading-layout analysis runs.
- Existing chapter loading indicators remain unchanged.

## Infrastructure

- Added Supabase tables for release metadata and push subscriptions with row-level security enabled.
- Added Render configuration for the release service environment variables.
- Added a protected release-sync endpoint authenticated by `RELEASE_SYNC_SECRET`.
