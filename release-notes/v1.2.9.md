# Yomite v1.2.9

### What's Changed

This release delivers a major update to Yomite's interface, authentication flow, app update system, notifications, reader experience, and Android release infrastructure.

### Highlights

- Added a dedicated full-screen authentication experience.
- Added GitHub Release-based app update detection.
- Added an in-app update modal with release notes and installation support.
- Improved light and dark theme consistency across the app.
- Improved manga details, profile, settings, and More screens.
- Added better notification opt-in behavior.
- Improved Android release automation and APK validation.

### New App Update System

- Added automatic GitHub release checks when the app starts on Android.
- Added manual update checking from the More screen.
- The latest version displayed in the More screen is fetched directly from the latest GitHub Release tag.
- Added a full-screen update modal with:
  - Current release version
  - Release title
  - Release notes
  - Features and bug fixes
  - Scrollable content for long descriptions
  - Floating "Install Update" and "Later" actions
  - Theme-aware light and dark styling
  - Animated opening and closing transitions
  - GitHub release link
  - Yomite branding and application icon
- Added Android APK downloading and installation support.
- Added a developer-only update modal preview button for Expo Go.
- The preview button is hidden from standalone and production builds.

### App Update Notifications

- Added notifications when a newer GitHub release is detected.
- Notifications are sent only to users who enabled notifications.
- The same release is announced only once per device.
- Notification permission is no longer automatically requested on first launch.
- Notification settings remain disabled by default until explicitly enabled by the user.
- Added release version and release information to the notification payload.
- Tapping an update notification directs the user to the app update section.

### Authentication

- Added a dedicated full-screen login screen.
- Added email and password authentication support.
- Added registration support with preferred username handling.
- Added Google authentication support.
- Improved keyboard handling and form layout.
- Added accessible labels and native haptic feedback.
- Added login-related artwork and branding assets.
- Added authentication routing through Expo Router.
- Added improved navigation from the More screen, profile screen, and reader screens.

### More Screen

- Added an account section with signed-in user details.
- Added profile avatar and display name information.
- Added direct navigation to the profile screen.
- Added a sign-in entry point for logged-out users.
- Added a GitHub-based "Check for App Updates" action.
- Added the current application version dynamically.
- Improved the flat divided-list layout.
- Improved spacing, icons, subtitles, and theme-aware interactions.

### Settings

- Notification toggle now starts disabled for new installations.
- Notification permission is requested only when the user enables notifications.
- Improved settings back navigation.
- Added support for returning to the profile screen.
- Simplified account-related settings and moved account access to the More screen.
- Improved the settings layout across mobile and desktop screen sizes.
- Improved theme, appearance, reading mode, and storage sections.

### Manga Details and Reader Experience

- Improved manga title visibility in light mode.
- Improved author text contrast over the hero artwork.
- Added theme-aware hero gradients.
- Reduced excessive backdrop whiteness in light mode.
- Updated navigation icon colors for light and dark themes.
- Back, bookmark, and download icons now remain visible in both color schemes.
- Improved manga detail layout and visual hierarchy.
- Improved reader-related navigation and interaction states.

### Notifications and Background Scanning

- Background chapter scanning is now disabled by default.
- Added explicit notification opt-in behavior.
- Added a new background scan configuration storage version.
- Improved notification channel and application icon handling.
- Improved notification safety for Expo Go and unsupported environments.

### Manga Sources and Data

- Improved MangaDex API handling.
- Improved source adapter behavior.
- Updated Asura Scans parsing logic.
- Improved chapter and manga source compatibility.
- Improved cloud synchronization and user store behavior.
- Improved history, discovery, and downloaded content interactions.

### Android Build and Release Improvements

- Added Android release signing plugin configuration.
- Added keystore-based release signing validation.
- Added APK version and version code verification.
- Added APK certificate verification.
- Added ABI validation for arm64 and universal APKs.
- Added SHA-256 checksum generation for release APKs.
- Improved GitHub Actions Android release automation.
- Updated Android SDK setup and automatic license acceptance.
- Updated GitHub Actions to Node.js 24-compatible versions.
- Pinned release runners to Ubuntu 24.04.
- Added automated APK artifact upload and GitHub Release publishing.
- Added detailed release notes generation from versioned Markdown templates.

### Bug Fixes

- Fixed stale TypeScript errors on the login screen.
- Fixed login route configuration.
- Fixed notification permission being enabled by default.
- Fixed light-mode text visibility on manga detail screens.
- Fixed light-mode navigation icon contrast.
- Fixed update modal content overflowing without scrolling.
- Fixed update modal actions scrolling with the release content.
- Fixed sticky update modal header contrast during scrolling.
- Fixed app version text being hardcoded in the More screen.
- Fixed update modal preview appearing in production builds.
- Fixed Android release workflow SDK license prompts.
- Fixed release APK validation paths after APK filename updates.

### Installation

Download the universal APK below for most Android devices.

For supported arm64 devices, the smaller arm64 APK may be used instead.

Verify the downloaded file using the included `SHA256SUMS` file when available.
